# Data - Table of Contents
1. `manatee.npy` - Recording of a manatee call underwater.
    1. Rycyk, A., V. Cargille, D. Bolaji, C. Factheu, U. Ejimadu, C. Berchem, and A. Takoukam Kamla. 2025. Bioacoustic Dataset of African and Florida Manatee Vocalizations for Machine Learning Applications, 2020-2022 ver 2. Environmental Data Initiative. https://doi.org/10.6073/pasta/c73edcb4a36ed07aebfbe238a31ceb19*.
3. Various Images - Example SAS beamforming images that will (hopefully) be created/replicated by tutorial attendees.
4. `sas_proj_signal.npy` - Projected chirp signal from an example HDF5 file output by [MASTODON](https://github.com/Sonar-Sim/MASTODON). To be shared during tutorial session.
5. `sas_recv_pings.npy` - Raw ping data from example HDF5 file output by [MASTODON](https://github.com/Sonar-Sim/MASTODON). To be shared during tutorial session (file was too large to upload).
6. `sas_pulse_compress.npy` - Pulse-compressed ping data derived from example HDF5 file output by [MASTODON](https://github.com/Sonar-Sim/MASTODON). To be shared during tutorial session (file was too large to upload).
7. `PointLinear1.h5` - Single-element platform pinging a point scatterer at 10m across-track with a projected delta signal.
8. `PointLinear2.h5` - Multi-element platform pinging a point scatterer at 10m across-track with a projected chirp signal.
9. `ReadStaveData.py` - Example HDF5 file reader for simulated [MASTODON](https://github.com/Sonar-Sim/MASTODON) data. This is used for reading `PointLinear1.h5` and `PointLinear2.h5`.
